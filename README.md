# brain

Claude Code に読ませる経営の前提集。事実と骨格だけを置く。

## 使い方

- このディレクトリで `claude` を起動する。CLAUDE.md が自動で読まれる
- 会社の話をすると、Claude は該当する会社のファイルだけ読む
- 変動する数字（売上・進捗・直近のやりとり）はここに置かない。各ツールから取る

## 書くときの基準

- 残す/消すは「3ヶ月後の自分が読んで役立つか」
- 事実（立て付け・体制・決定事項）と骨格（方針・判断基準・用語）だけ。議論ログとドラフトは置かない
- 追記には日付（YYYY-MM-DD）。推測は「要確認」と明記
- 特定の会社の話はその会社のファイル。会社をまたぐ話は me/me.md（HR の共通基準は hr.md）
- 変更したら commit & push

細かいルールは CLAUDE.md にある。
