# Hello の課金と原価

Hello（helloai/hello.md）のプランと原価。2026-11-24 に作り直した（9-27 の「電話とトークンを混ぜた 3 プラン」を置き換え）。仕様の正本は GitHub hello-ai/hello #3463。

## 方針（2026-11-24）

- AI の利用はクレジット、電話は別の商品として売る。AI のプラン名は Free / Plus / Max（Muse の Free / Power / Maximum と同じく量で付ける）
- AI はトークン数でなく原価に比例するクレジットで数える（モデルで単価が違うため）。1クレジット = 原価 0.1円。ユーザーにはクレジットの数で見せる
- サブスクでは大きく儲けない。価格は「上限まで使う人でも赤字にならない」線で決める。稼ぐのは toB 側（予約サイト・店・決済）
- プランのクレジットは追加購入より 1クレジットが安い（追加購入が続く人をプラン変更に誘導する）
- 電話は Web のクレカ決済だけで売り、アプリ内課金や AI のクレジットと混ぜない。トークンは iOS ではアプリ内課金（IAP）が必須。番号と通話は「アプリ外で消費されるサービス」として IAP から外す（審査で通るかは要確認）
- 円・ドル・ウォン・台湾ドルで出す。クレジットは全世界で同じ単位・同じ量にし、通貨ごとに変えるのは価格だけ

## 電話

| | 無料 | 有料（円） | 有料（ドル） |
|---|---|---|---|
| 価格 | 0 | 1,480円 / 月 | $7.99 / 月 |
| 番号 | 共通の番号（発信のみ） | 専用の番号 | 専用の番号 |
| 月の分数 | 15分 | 60分 | 120分 |
| 超えた分 | ― | 1分 20円 | 1分 $0.05 |

- 月額は各月の開始時に前払い。超えた分は更新日に締めて次の月の月額と一緒に請求（後払い）
- 超過が 3,000円 / $20 に達するごとに請求し、カードが通らなければ止める。月 10,000円 / $70 で止めて本人に確認（不正利用の歯止め）
- ドルは米国の通話原価が未確認（Twilio の記憶値）。ウォン・台湾ドルの電話は各国の番号と原価を確認して決める

## 原価（2026-11-24）

- LLM（100万トークンあたり）: 入力 $0.3 / キャッシュ読み取り $0.006 / 出力 $1.2
- 播口の実使用（32日間）: 原価 $10.24（約1,540円）、入力 1.28億 / 出力 150万トークン、キャッシュヒット 78%、返信 928回（1日約29回）。平均 100万トークン $0.079（約11.9円）、返信 1回 約1.65円（約17クレジット）
- VM の費用は上の実績に入っていない。クレジットに含めるか会社持ちかは要確認（CTO）
- 050 番号: 月 120 円（初月 240 円）。着信 1 分 0.3 円。発信 1 分 固定 3.2 円 / 携帯 10.5 円。本人確認 1 回 220 円
- 音声 AI（1 分あたり、聞く 30 秒 + 話す 30 秒）: Gemini 3.8 Live 1.7 円 / GPT-Live 1 は約 9.5 円 / Gemini 3.8 Flash TTS 構成 1.9〜2.4 円（2027-01 から約 3.2 円）。原価だけなら Gemini 3.8 Live が本命
- 為替の前提: $1 = 150円 / ₩1,400 / NT$31

## 損益（円・税抜き・手数料後、推測）

手数料は Web 3.6% / アプリ内課金 26%。消費税 10% を抜く。

|---|---|
| 無料 | −350円 |
| Plus | +973円 / +805円 |
| Max | +1,836円 / +1,593円 |
| 追加購入 5,000 / 20,000 / 100,000 | +552 / +2,031 / +9,105円（Web）、+509 / +1,767 / +7,491円（アプリ内） |

- 上限まで使う人でも全プラン黒字（無料を除く）。播口でも原価月 1,540 円なので、上限に当たる人は少ない見込み
