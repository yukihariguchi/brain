### 入会フロー

1. Instagram・紹介で興味を持つ → 会員サイトのウェイティングリストに登録
2. 知らない人なら info@haku.restaurant から素性確認メール（職業・勤務先・SNS・紹介者）
3. 審査（上記）→ OK なら入会手続きの案内（登録・カード決済）→ 決済確認
4. 公式 LINE の案内メールを送る。以後の予約は公式 LINE
5. 会員リストに記録（氏名・種別・入金日・次回更新日・経路・LINE 案内済）

- 法人・請求書払いは例外対応。しろう OK が前提。システム上カード登録は必須なので登録はしてもらうが課金しない。請求書は INVOY で発行し、着金を確認して正式会員

## 会計・入金（2026-11-08）

- 売上は 2系統。カード決済（SBペイメント端末 / respo iPad）は毎月 15日に GMOあおぞらへ入金。請求書払い（INVOY）は入金を確認して消し込む
- 価格: 売値（税抜）→ サービス料 10% → 消費税 10% = 売値（税抜）× 1.21。メニューは税込表記（端数切り上げ）。管理の正は台帳の税抜値
- 月次: カード入金（15日）と端末売上の突合、会費・請求書払いの着金確認と未入金フォロー、ワインの原価と売上から粗利を把握
- ワイン台帳: ワイン発注 LINE を AI に読ませて作成。売上・原価・在庫・棚卸はこの台帳が正。棚卸は月1回、リストと現物を突合。カタカナの表記ゆれ（ビゾー / ビゾ、ドルーアン / ドルアン）は生産者名と畑名の両方で探す。同銘柄のヴィンテージ違いがあるので VT まで確認
- 備品・テナント初期費用の立替は瑞花（しろうの会社）から請求

## 予約・PR（2026-11-08）

- 予約・問い合わせの窓口は公式 LINE に一本化。しろう個人に来た連絡も公式 LINE へ誘導。会費などの金額は DM に書かず会員サイトに誘導
- 公式 LINE と Instagram DM の返信はシフト担当者。営業時間外は「店長」
- Instagram のフィード・リール・レタッチは PR チーム（鈴木）。現場はストーリー・リポスト・素材の共有フォルダ格納
- トーンは「清潔感・静けさ・余白」。定員・会費は出さない。客の顔は出さない。投稿はしろう本人の発信が基本（一人称「僕」）
