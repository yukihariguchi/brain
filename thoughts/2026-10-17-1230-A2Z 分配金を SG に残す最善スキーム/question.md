# 論点

HGJP が受け取る A2Z 共同事業の分配金（月 約1億円）を、合法かつ税務上守れる形で最も多く HGSG（シンガポール）に残す構造は何か。現行案（債権譲渡 5%・経営指導 人数×400万円・購買代行 実費＋5%）より優れたスキームがあるか。

## 背景（事実）

当事者
- HGJP: 株式会社Harry&Gucci。播口の日本の資産管理会社。播口が 100% 保有。日本での買収の箱。投資先は AISAACJP 26.7%、株式会社白 25%、H2T2 50%、サンクチュアリ
- HGSG: 播口のシンガポール法人。播口が 100% 保有。H&G グループのヘッドカンパニー。SG 在住の取締役が播口以外にいる。従業員あり（給与は1人月 約200万円）。第三者顧客に投資判断支援・事業開発・M&A 助言を 1人月 400万円で売っている実績がある
- HGJP と HGSG の間に今は資本関係がない。2027年中に播口 → HGSG → HGJP の2階建てに組み替える予定（HGSG が HGJP 株を播口から分割払いで買う）
- 播口は 2026年11月に日本を出国する。出国後の居住地は UK（FIG 制度を使う前提。到着後4年は海外所得・海外譲渡益が非課税）。出国時に国外転出時課税（15.315%）がかかる
- A2Z: 松本氏の資産管理会社が 100% 保有する日本法人。子会社 Rise が myfans（アダルトサービス）を運営し、A2Z グループの利益の約 95% を作る。播口と田中（オーサム）が経営を任されているが登記上の役員ではない。Hello / aisaac / HGJP との資本関係はなく、公開情報で播口とつながる線はない。関係を出さない方針
- A2Z の全事業（Rise を含む）は HGJP / AWSM JP / aisaac との共同事業契約。毎月の営業利益を aisaac 22% / AWSM JP 14% / HGJP 14% / A2Z 50% で分配する。契約の法形式（任意組合 / 匿名組合 / 利益分配契約）は未確認
- 松本氏は事業と HGSG との契約（たとえば HGSG が当事者になる契約変更）にはおそらく応じるが、確認していない

資金の流れ
- myfans の海外決済代行からの入金は、すべて A2Z の香港子会社 Contents & Technology（C&T）に入る（ユーロ・ドル建て）
- HGJP の分配金は C&T から HGSG の Wise にユーロと円で直接振り込まれている（通貨の内訳は HGSG の希望で分けてもらう）。HGJP の口座には入っていない
- 日本からの海外送金は銀行の資金源確認が厳しく、SG → 日本の送金は同一オーナーのグループ会社間なので容易。これがこの経路の価値
- HGJP の分配金は年 約12億円

税務・規制の前提
- 日本の法人実効税率 約30%、SG 17%。HGJP → HGSG の配当は日星租税条約で源泉 5%（25% 以上を6ヶ月保有が条件）。HGSG → HGJP の利息は SG で源泉 10%
- HGJP と HGSG は国外関連者で、移転価格税制の対象。独立企業間価格を超える対価は国外関連者への寄附金で損金不算入
- SG の Payment Services Act: 「HGJP のために HGSG が送受金する」形（収納代行・送金代行）は cross-border money transfer に入り、関連会社除外は関連会社同士の支払にしか効かない（支払人 C&T は A2Z 側）。本業のある会社が行うと副業として営むと推定され反証不可（s5(2)）。罰則は法人 25万 SGD 以下。ライセンス（SPI）は取れるが規制業の体制が要る
- Wise のビジネス規約 12.1(f): 口座の資金は自社のものであること。AUP は「第三者のための送金」「決済処理」とポルノ・性的サービスを非対応業種にしている（may be declined）
- 日本で行った経営管理役務の対価は国内源泉所得（所得税法161条1項6号）で、条約免除には届出と「日本に PE がない」ことが要る
- 2020年民法改正で譲渡制限特約があっても債権譲渡は有効（466条2項）。将来債権の譲渡も有効（466条の6）
- 播口は HGJP の取締役。非居住者役員への役員報酬は源泉 20.42%
- 出国前の播口は HGSG の 100% 株主として個人の外国子会社合算税制の対象。HGSG の決算期末は未確認
- HGSG が契約しているプライベートジェット（NetJets）は 2026年で 5,000万円分。HGSG が価格交渉をしている

## 議論の経過

却下した案と理由
- 収納代行 10%: 受取・転送の機能に対して独立企業間価格にならない。超過分が寄附金で損金不算入＋SG で 17% の二重課税
- 収納代行・送金代行 2.5% / 1.5%: SG の決済サービス法と Wise 規約に抵触（2回調査して通る道なし）。認可を取っても比較対象は決済手数料 1% 前後
- HGSG が A2Z 共同事業の経営関与を役務として HGJP に提供する: HGJP が導管に見え、A2Z 側に HGSG と播口が出る。関係を出さない方針と衝突。HGJP の義務を国外法人に再委託する構図は相手方の了解が要る
- 経営指導料を原価加算（総原価 × 1.05〜1.3）で決める: HGSG に第三者への同単価の販売実績があるので内部比較対象を使うほうが強い
- 債権譲渡登記・A2Z への譲渡通知: 播口が不要と判断。契約書のみで進める（税務で担保付き貸付に引き直されるリスクは承知）
- HGSG を共同事業の当事者にする: 関係を出さない方針と衝突。契約形式次第で分配金が日本の国内源泉所得になり源泉徴収が残る可能性。深くは検討していない

現行案の限界として指摘済みのこと
- 役務対価で動かせるのは年 1〜2億円（割引料 6,000万円＋経営指導 人数×4,800万円＋購買代行 費用の 5%）。分配金 12億円の 1〜2割
- 残り 10億円は日本で法人税を払い、2階建て後に配当（源泉 5%）で SG に移す経路しかない
- 1円あたりの節税は日本の損金 約30% と SG 17% の差で約 13 ポイント

## 現在の仮説

HGJP が共同事業の当事者のままである限り、現行案（債権譲渡 5%・経営指導 人数×400万円・購買代行 実費＋5%、精算は帳簿上の相殺、残りは2階建て後の配当）が、合法で守れる範囲の上限。これより多く SG に残す構造は、HGSG を共同事業の当事者にする以外に無い。

問いたいこと
1. 現行案より多く SG に残せて、移転価格・決済規制・関係を出さない方針の3つを同時に満たすスキームはあるか
2. 「HGSG を当事者にする」案を関係を出さずに実現する形はあるか（たとえば HGSG の 100% 子会社化後の HGJP の位置づけ、A2Z 側の契約相手を変えない形）
3. 現行案の中で見落としている損（税・規制・否認リスク）はあるか
