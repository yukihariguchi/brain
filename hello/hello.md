## 方針・判断基準

### HelloDining のエージェント時代の戦略（2026-09-23 方針）

前提: Muse（Meta、2026-09 米国）等の汎用エージェントが店を探し、電話し、予約する。探す・比べる・予約する・払うの手間はエージェントが持っていく。残るのは店の中で起きる事実（来店・注文・再訪）と、人の趣味。

一言で: 店側の受付を取りながら、人の食の事実を AR に残し、その両方を材料にした客側エージェントで「どこよりも良い店選びと確定」をやる。toB と toC は1つの学習ループの両端。

3つの構成要素

- 店側の陣取り（entry・Respo 電話 AI・台帳）: 確定できる供給と、来店・注文・再訪の事実の発生源。目標店舗数は HelloDining 戦略文書の通り。entry 契約の中身は「店の公式の AI 受付窓口の合意」
- ユーザー側の食の記録（AR）: 予約・来店・会計・注文から本人の手を介さず残る、本人所有の事実。食べログは他人の意見、Instagram は見せたい食事、AR は本当に食べたもの全部。記録から本人の味覚を学んだ分身が育ち、分身がエージェントに指示を出す。発信者の分身を借りられる。本人が「食事は AR」と指定する理由になる
- 客側の専用エージェント（AR の本体）: 全店の索引・鮮度・本人への適合・そのまま確定を一本の API で返す。AR アプリで直接使え、Muse・ChatGPT・Gemini・LINE から MCP/Apps で同じものが呼ばれる。精度は「一発で決まる率・確定率・再訪率」で測り、再訪を正解として学習する。結果で学習できるのは店側の事実を持つ Hello だけで、これが唯一の技術的な堀

回路: 店が増える → 事実が増える → 選ぶ精度が上がる → 人が AR を指定する → 予約が Hello を通る → 店が「AR の客が来る」と入る。表が Muse でも、店を選び確定を入れたのが Hello なら店にとっての集客源は Hello。台帳に「AR 経由・初来店・再訪」を見せる

測る数字: 受付を持つ店の数 / 記録を持つ人の数 / AR が選んだ店の再訪率

収益（消費者からは基本取らない）

- 指名予約（人気店・訪日客）の予約者手数料。条件で選ばれる店は店の月額。切替基準は店あたりのエージェント経由予約数
- 店からの成果報酬: AR が選んだ初来店客が再訪したら払う。送客手数料の後継。選択に金は入れない
- 決済（HelloPay）: デポジット・ノーショー・越境。贈る・前払い
- 事実の提供: 業務用メーカー（注文データの集計・同意つき試飲）、AI 会社（分身・店の事実・確定の従量）、健康経営・保険（自動の食事記録）
- 機械同士の取引所（後段）: 店が事前ルールで即時に値付け（当日の空席値引きは時間で縛る）。グルメサイトの店側課金の置き換え。評価とは分離

守る線: 分身の選択に金を入れない。ここが崩れると成果報酬も従量も価値を失う

展開: 予約が電話で店の連絡手段が WhatsApp でない国。日本 → 韓国・台湾・香港・タイ・SG → 欧州観光都市。米国は最後。人気店は 30 都市に集中するので人が取り、ロングテールは AI 営業。電話で予約する他業種へ同じ形で広げる。仮想チェーン本部（仕入れ共同購買・資金・人・開業・売却）は店側の長期の絵

却下した案: 客側の世界共通アカウント（身元と決済はエージェントが持つ）/ 確定 API を堀と見ること（大手は自国で自前化、期限つきの入口）/ 汎用エージェント / 個人店をまたぐ会員証 / 消費者の月額 / Muse から取る（代替のない供給がある場面だけ）/ 送客手数料を予約者負担に全面置換する看板 / AR アプリの画面投資（戦略文書 5〜8）を先にやること / 排他条項の検討（独禁法の水準になってから）

崩れる条件: Google が店側に無料の電話 AI と台帳を配る（播口は来ないと見る）/ カカクコムが外部連携のクロールを遮断（1〜2 年で先方が認めた統合へ）/ Meta が Respo と同じ店側の網を持つ / 記録が「気持ち悪い」に転ぶ（何が残り誰に見えるかは本人が握る）/ Instagram が食の記録の社交を取る（防御は事実と検証）

利益の置き場（2026-09-22）

- 利益は稼いだ国で課税され、動かせるのは機能と人。売上を SG につけても取り分は変わらない
- Hello SG が本人（残余利益を取る側）になる条件は、SG の執行役員が実際に意思決定しリスクを負うこと。日本の社員が Slack で決めていると調査で崩れる

- toC の IP を Hello SG に置くなら、Hello JP から時価で移す（含み益に約 30%）。純資産マイナスの今が一番安い。DCF で見られるのでゼロにはならない。要確認
