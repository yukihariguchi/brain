# Hello（パーソナルアシスタント）

Hello が出す汎用パーソナルアシスタント。サービス名は Hello（2026-09-24 決定）。HelloDining とは別の新サービスとして考える。
このファイルは「他のプレイヤーにどう勝つか」だけを書く。決定済みの細かい仕様は hello/hello-spec.md、法人・体制は hello/base.md。

## 一言で

電話のイライラを取る。AI が本人の代わりに電話し、本人は実況を見て、指示を出し、いつでも自分が出られる。

## 取る位置（2026-09-24）

- 相手が API も Web も持たない現実世界（店・病院・業者・役所）に、電話で届く。検索エンジンもエージェントも届かない領域で、電話をかけるコストが下がった瞬間に開く
- 予約だけでなく「今の状態を聞く」（行列・空席・在庫・見積もり）、比べる（3 軒に同時に聞く）、手続き（変更・再配達・保留待ち）、受ける（折り返し・宅配・営業電話の遮断）
- 会話の場（LINE・Instagram・OS）は取らない。取るのは「決めた後の実行」と「電話の窓口」

## なぜ Hello が勝てるか

他社との差は「本人が電話の中に居られる」ことと、HelloX と HelloPay の掛け合わせ。

- Apple・Google: 本人の携帯番号への着信を端末の中で受け、用件を文字にするまで（Pixel の Call Screen は 2018 年から、iOS 26 は日本語対応）。Hello は Hello の番号を網の側で受け、受けた後に予約や変更まで動く。Google は Duplex・Call Screen・Pixel と部品を全部持つので、優位の寿命は 12〜24 か月と見る
- Meta Muse: 電話を人のコールセンターに隠れてやらせて叩かれた（2026-09）。米国限定・英語のみ。Hello は「本人が出る」を正面から製品にする
- LINE ヤフー Agent i: トークルームの中。Hello はそこと競わず、電話と実行を取る

Hello にしかできない 3 つ（HelloX × HelloPay）

1. カード保証つきの予約電話: 無断キャンセル時にデポジットが取れる予約として店に伝えられる。店が AI の電話を受ける理由になる
2. 電話で交渉して、その場で払う: 見積もり → 交渉 → 支払いまで 1 本の電話で終わる。Web も API も無い相手に決済まで届く
3. 相手も HelloX なら音声でなくデータで済む: HelloX 導入先が増えるほど Hello の完了率が上がり、日本語の音声 AI の精度問題を飛ばせる

## 早い者勝ちが成立する条件

パーソナルアシスタントは一度選ぶと変えにくい。ただし残るのは切替費用が積まれた分だけ。取った数より、1 人あたりに積まれた量が守りの厚さ。

- 積まれるもの: 本人が外に出した Hello の番号（店・病院・宅配の連絡先に入る）/ 記録（どこに何を頼み、何と言われたか）/ 保存済みのログインセッションとカード / 委任の設定
- 積まれないもの: チャット画面、モデルの賢さ、実況の UI。相手が同じ物を出せば差が消える
- テスター版から「番号を外に出す」「記録を残す」は落とさない

## 重要な決定（詳細は hello/hello-spec.md）

- 引き継ぎは本人がやる。運用部隊は Hello には使わない。本人が出なければ「折り返します」と言って切る（2026-09-24）
- 決済は本人のカード。HelloPay の PCI DSS で番号を保管し、毎回本人が打つのは CVV と本人認証だけ。認証画面はエージェントのブラウザを本人の端末に映す Live View で本人が打つ。コードを Hello に転送させない（2026-09-24）
- 電話番号はプール方式から。1 人 1 本は数字を見て切り替える。SMS は使わない（2026-09-24）
- Web 操作は AI が手順を作りコードが実行する。AI に毎回操作させない。LLM は 3 層（判断は上位、量は安価、音声は HelloX）で切り替え可能にする（2026-09-24）

## やらないこと

- 自前のチャットや連絡先で LINE を置き換えに行く（会話の場は取らない）
- 運用部隊で電話を引き取る
- 自前の LLM
- 電話でカード番号を読み上げる、ワンタイムコードを Hello に送らせる

## 測る数字

- 90 日後に残っている率 / 1 ユーザーあたりの積み上げ（外に出した番号の使用回数・記録の件数・保存セッション数）
- 依頼から確定までの中央値 / 本人の介入なしで確定した率 / 店が電話を切った率 / 「確定」と表示して予約が無かった率
