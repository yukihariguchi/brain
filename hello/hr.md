### 契約上、Hello 側に不利な条項（事実）

- 引き抜き禁止の期間と違約金は4社で大きく違う。Hajimari 無期限・300万円 / レバテック 3年・委託料1年分 / BE 6ヶ月・委託料6ヶ月分 / Findy 規定なし（申込書は要確認）
- Hajimari: 損害賠償の上限が Hajimari 側だけにある。Hello 側は無制限
- Hajimari: 精算が月末60分単位切り捨て。1分単位（BE）より Hello が損する方向
- Hajimari / BE / レバテック: 基本契約に Hello 都合の予告解約がない。Findy は30日予告で可
- BE: 基本契約の終了通知が満了3ヶ月前。他社は1ヶ月前
- BE: 注文書を5日放置すると受諾扱い
- レバテック: 精算15分単位。特許等の権利が発明者側に帰属し、LT 単独発明は Hello に移らない。損害賠償請求は終了確認から12ヶ月で失効
- Findy: 手数料15%を1年ごとの覚書で維持している。覚書が切れると申込書の標準料率に戻る（標準料率は要確認）

### CodeCast への付け替え

目的: 各社経由の副業エンジニア契約を CodeCast 経由に切り替え、手数料を下げる。

#### 手数料の比較

| 経路 | 手数料 | 根拠 |
|---|---|---|
| CodeCast | 稼働報酬の 10% | ユーザー申告（2026-09-18）。codecast.md の標準料金は 15%。Hello 向け料率かは要確認 |
| Findy | 15% | 覚書（2024-04-08）に明記 |
| レバテック / Hajimari / BE | 20〜25% | ユーザー推定。単価に内包され契約書に内訳なし |

- 3社（Hajimari / レバテック / BE）とも「乙の書面承諾があれば可」の例外がある。承諾を取る交渉が正攻法
- Hello と CodeCast に資本関係はない（codecast.md）。ただし播口の関与の形は要確認。関与が強いと「間接契約」「脱法」と見られる材料になる
- 契約書の解釈は弁護士確認が必要。ここは論点の整理まで

#### 付け替えの前に決めること（論点）

- どの媒体から着手するか。リスクの低い順は Findy → BE → レバテック → Hajimari
- 承諾を取る場合の対価。違約金の水準（300万円 / 委託料1年分 / 6ヶ月分）が上限の目安になる
- 承諾を取らずに待つ場合、BE は6ヶ月、レバテックは3年、Hajimari は消えない
- CodeCast の 10% が Hello 向け特別料率なら、その根拠と期間を CodeCast 側と文書化するか

### 用語

- 準委任: 成果物でなく稼働に対して報酬を払う業務委託。契約不適合責任を負わない
- IT プロ: Hajimari の用語。Hajimari から再委託を受けて稼働するフリーランス
- システム利用料: Findy の用語。フリーランス報酬に上乗せして Findy が受け取る手数料
- 付け替え: エージェント経由の契約を解消し、同じエンジニアと CodeCast 経由で契約し直すこと
