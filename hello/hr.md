### 3. 争ったときの勝ち筋

- 文言論: Hello の契約相手は CodeCast で、条項は「直接に」と限定している。LT・BE に使える。見込み4〜6割
- 補強: 向こうの定型書式で、Hajimari のように「間接」と書けたのに書かなかった（作成者不利）。CodeCast は独立した事業者で隠れ蓑ではない
- 向こうの反論は趣旨論。「条項の目的は紹介料の保護で、直接か間接かは本質でない」。これが先に採られると文言論は届かない
- 負けたときは減額。違約金と実損（残存期間の手数料）の乖離、無期限・3年の拘束の過大さを突く。BE の6ヶ月が相場の証拠。減額和解が現実的な着地
- Hajimari は文言論が使えず減額のみ

### 4. 方針（2026-09-18）

契約経路を CodeCast に集約する。集客力が足りないうちは Findy とレバテックを併用する。契約条件は Hello 雛形を基準にする。

| 相手 | 契約方針 |
|---|---|
| CodeCast | 切替先。手取りの提示と契約は CodeCast が行う |
| Findy・レバテック | 今は切れない。新規も継続。他社を雛形に切り替えた結果を見て最終判断。並行して条件修正を持ち込む。LT は12条相当の変更覚書、Findy は申込書の特約（禁止期間1年→6ヶ月、9条5項の適用除外、成功報酬免除） |
| Hajimari・BE | 雛形かそれに近い条件でなければ契約終了の方向。終了までは抑止のため少額の発注を残す |
| 4社以外の新規 | Hello 雛形でなければ契約しない |

#### 雛形の要点

禁止条項は消さず、法務が「調整」と読む条項を重ねて、切替時に請求できる額を下げる。

| 条 | 内容 |
|---|---|
| 1条 | 旧基本契約は終了し、進行中の個別契約にも本契約を適用。主要条項は個別契約で上書き不可 |
| 4条 | 1分精算・端数処理なし。費用込み。振込手数料は乙。遅延損害金は法定利率 |
| 12条 | 禁止は「甲が勧誘して」「直接に」契約した場合のみ。終了後6か月。乙または本人の申し出で終了した場合は適用外。違約金は乙手数料（委託料と本人報酬の差額）の6か月分が上限、乙は手数料額を証する資料を提示 |
| 13条 | 損害賠償は直接損害のみ、直近12か月の委託料が上限、双方対称。弁護士費用は対象外 |
| 15条 | 30日予告で中途解約（双方） |
| その他 | 放置を承諾とみなさない（3条）/ 知財は発生時に甲帰属（9条）/ 乙の利用規約は甲を拘束しない（20条） |

- 法務が突きそうな箇所: 12条の6か月と資料提示義務 / 「本人の申し出」の除外 / 振込手数料
- 却下済み: 条項削除、他エージェント経由の明示除外、過去債権を消す清算条項、移籍料
- 並行して単価10%減を全社に要求する

#### 雛形が提訴を抑止する仕組み

- 狙いは「訴えられても勝つ」ではなく「訴える判断をさせない」。回収額を弁護士費用（100〜200万円、敗訴者負担なし）と同水準まで下げる。1人・月80万・手数料20%なら、LT 約960万円 → 乙手数料6か月 ≈ 96万円
- 勧誘要件で立証の負担が向こうに移る。契約と稼働は紙が残り提訴後に取れるが、勧誘は会話で、証明手段は本人の証言だけ。本人は訴訟の外では答える義務がなく、訴訟の中では断れず真実を言う義務がある
- 効かない条件: まとめて訴えられる（10人で1,000万円）／ 向こうが失う取引がなくなる

### 5. 運用

- 切替は Hello が本人に提案する（2026-09-18 決定）。「本人の選択」の防御は使わず、請求されたら払う額を織り込んで進める。文面は工夫しない。虚偽だけは書かない
- 切替した人と出身媒体は Notion のメンバー一覧で管理。本人には、本人側のエージェント契約に直接取引禁止が入っている可能性を伝える
- エージェントへの報告義務はない。問い合わせは「個別の契約状況は回答しない」で統一。窓口は1人。契約条件は全員一律で秘密保持（CodeCast 契約に NDA）
- 虚偽は言わない、言わせない。隠す工作もしない。民事が刑事になるか、故意の証拠が増える
- 内容証明が来たら自分で返信せず弁護士へ。本人にも連絡しない
- 力関係: 各社に手数料ベースで月約200万円を払っている（要確認: 月額か）。発注が残っている間は向こうは動きにくく、請求されたら発注の全停止を選択肢に持てる。切替が進むほどこの力は減り、発生済みの債権は消えない
