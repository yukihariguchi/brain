書き分け: 「確定」は書面（契約書・請求書・明細）で裏が取れたもの。「未確定」は Slack や口頭の説明・見込み・交渉中のもの。未確定は書面が出た時点で確定に移す。

### 未確定（Slack・口頭）

料金体系の説明（M.Hail 経由、2026-10-22）

- 体系は「カードブランド側の原価（インターチェンジ＋ブランド手数料）＋ 1.5%」。円建ては ＋1%。発行国で原価が変わる
- 当初見積もりの「カードブランド費用 約 2%」はインターチェンジ想定で、日本発行カードの Cross-Border Fee 等を含んでいなかった可能性がある。Mobius に確認中
- ディスカウント 1.5% + $0.05 は EC Suite のマージン相当（林の推測）

実績の読み方で未確認のこと

- 9.59% にリザーブを含むか（宮村の問い。未回答）
- 9.59% にゲートウェイ請求書 $21,325.80 を含むか。含まなければ合計は売上比 約 10.7%（売上を約 $197 万と逆算）
- statement のオーソリ $0.20/回 とゲートウェイの $0.10/回 が別建て（合計 $0.30/回）か、同じものの二重計上か

高い原因と改善の見込み（2026-10-16）

- オーソリ件数が売上件数の 2 倍以上。カード登録時に 0 ドルオーソリ（Zero-Dollar Authorization）を 1 回、決済時にもう 1 回打っている。Mobius 確認で直近約 10 日間に 0 ドルオーソリが 33,000 件超。Mobius からも見直し推奨
- 海外発行カード向けのカードブランド手数料（Visa ISA・MC Cross Border・多通貨処理）が最大。USD 建てにしてもユーザー側に手数料が乗るので効果は薄い（conan）
- オーソリを減らしても約 8% は残る見込み（conan の試算）
- 日本発行カードだと全体で 9% 超。US 発行なら海外手数料がかからないので、まず US・カナダのユーザー分を Mobius に流す（conan の方針。決定ではない）

## CCBill

### 確定（書面）

出典: CCBill Adult Fees and Holdback Addendum（v.8、DocuSign）。審査中なので見積もり段階だが、料率は書面。料率は返金差引後の総売上に対してかかる。CCBill は料率をいつでも変更できる。

| 項目 | 料率 |
|---|---|
| 初期費用 / 月額 | $0 / $0 |
| 処理手数料 | 6.9%（週次ボリューム 0〜50,001+ の全階層で同率） |
| 取引ごと | $0.35/件 |
| EU/UK 加盟店サーチャージ、継続課金サーチャージ | なし |
| チャージバック | $25/件 |
| RDR（Rapid Dispute Resolution） | $0 |
| 返金 | $0.15/件 |
| Visa 高リスク登録料 / Mastercard 高リスク登録料 | $950/年 / $1,000/年（パススルー。予告なく変動） |
| 保証金（Security Deposit Holdback） | 総処理額の 5%、26 週間 |

- 週次入金。入金額 = 顧客請求額 − マージン − 保証金 − 返金 − チャージバック − ACH 返戻 − 送金手数料 − 税・罰金。CCBill は保証金からの充当と積み増し要求ができる

### 未確定（Slack・口頭）

- FX Fee・Cross-Border Fee は 6.9% に含まれ、別途かからない（CCBill の回答を M.Hail が共有、2026-10-22。Addendum には明記なし）
- 込み込み 7% なら waffo（Visa/MC 7.3% + €0.30）より安い（conan）

料率交渉（2026-10-22。口頭ベース）

- CCBill の Jeff（OnlyFans を初期から担当。M.Hail が面識あり）に個別相談。決済ボリュームに応じた段階料率（Rate/Volume Tiers）を検討できる見込み、との回答
- Jeff は今後 6 ヶ月の CCBill での決済予定額を求めている。これを出せば具体交渉に入る
- 一般論として、3〜6 ヶ月の実績を積み、ボリュームとチャージバック率が安定した段階で見直しが通りやすい（M.Hail）
