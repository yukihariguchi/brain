# Rise（myfans）の決済代行

myfans の海外向けカード決済に使う決済代行（PSP）の立て付けと料率。入金先は A2Z の香港子会社 C&T（a2z-rise/base.md「資金の流れ」）。

## 全体（2026-10-22）

- US の決済代行は 2 社。MobiusPay（EC Suite）は審査済みで決済を流している。CCBill は審査中で、料率は見積もり段階
- 契約主体は Tokuneko Corp.（Torrance, CA。MobiusPay の請求書の宛先）。担当は Willian Hail（M.Hail）
- 月次の決済明細は Rise Slack #corp-us-general のスレッドに M.Hail がアップしている（Mobius / EC Suite ポータルから）

## MobiusPay（EC Suite）

請求は 2 本立て。処理手数料は EC Suite の statement で売上から差し引き、ゲートウェイ手数料は MobiusPay Inc が月次の請求書で ACH 回収する。

  - 9.59% にこの請求書が含まれているかは要確認。含まれていなければ合計は売上比 約 10.7%（売上を約 $197 万と逆算）
- 要確認: 処理手数料のオーソリ $0.20/回 とゲートウェイの $0.10/回 が別建て（合計 $0.30/回）か、同じものの二重計上か

### 高い原因と改善の余地（2026-10-16 時点）

- オーソリ件数が売上件数の 2 倍以上。カード登録時に 0 ドルオーソリ（Zero-Dollar Authorization）を 1 回、決済時にもう 1 回打っている。Mobius 確認で直近約 10 日間に 0 ドルオーソリが 33,000 件超。Mobius からも見直し推奨（0 ドルオーソリの成功は実決済の承認を保証しない）
- 海外発行カード向けのカードブランド手数料（Visa ISA・MC Cross Border・多通貨処理）が最大。USD 建てにしてもユーザー側に手数料が乗るので効果は薄い
- オーソリを減らしても約 8% は残る見込み（conan の試算）

## CCBill（見積もり。審査中）

出典: CCBill Adult Fees and Holdback Addendum（v.8、DocuSign）。料率は返金差引後の総売上に対してかかる。CCBill は料率をいつでも変更できる。

| 項目 | 料率 |
|---|---|
| 初期費用 / 月額 | $0 / $0 |
| 処理手数料 | 6.9%（週次ボリューム 0〜50,001+ の全階層で同率） |
| 取引ごと | $0.35/件 |
| EU/UK 加盟店サーチャージ、継続課金サーチャージ | なし |
| チャージバック | $25/件 |
| RDR（Rapid Dispute Resolution） | $0 |
| 返金 | $0.15/件 |
| Visa 高リスク登録料 / Mastercard 高リスク登録料 | $950/年 / $1,000/年（パススルー。予告なく変動） |
| 保証金（Security Deposit Holdback） | 総処理額の 5%、26 週間 |

- 週次入金。入金額 = 顧客請求額 − マージン − 保証金 − 返金 − チャージバック − ACH 返戻 − 送金手数料 − 税・罰金。CCBill は保証金からの充当と積み増し要求ができる
